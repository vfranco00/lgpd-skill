# Política de segurança

Reporte vulnerabilidades pelo reporte privado do GitHub: aba **Security** deste repositório, **Report a vulnerability**. O reporte fica visível só para quem reporta e para quem mantém o repositório.

Descreva o problema e como reproduzi-lo, sem segredo, credencial ou dado pessoal. Não abra issue pública para falha de segurança.
